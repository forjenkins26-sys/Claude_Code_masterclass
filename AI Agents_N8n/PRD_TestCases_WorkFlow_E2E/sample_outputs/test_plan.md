# Test Plan for VWO.com

## Objective
The objective of this test plan is to ensure that the VWO.com application, specifically the login and dashboard features, function as expected.

## Scope
The scope of this test plan includes testing the login and dashboard features of the VWO.com application.

## Test Strategy
The test strategy will involve a combination of positive and negative testing to cover valid and invalid login scenarios, as well as testing the dashboard feature after successful login.

## Test Types
The test types will include:
- Functional testing: to verify that the login and dashboard features work as expected
- Error handling testing: to verify that the application handles invalid login attempts correctly

## Environment
The tests will be run on the VWO.com application, which can be accessed at https://app.vwo.com/.

## Entry/Exit Criteria
The entry criteria for these tests are that the VWO.com application is accessible and the test environment is set up correctly.
The exit criteria are that all tests have been executed and the results have been documented.

## Risks
One risk is that the tests may not cover all possible scenarios, which could lead to issues being missed.
Another risk is that the tests may be flaky due to changes in the application or test environment.

## Tools
The tools used for testing will be Playwright for automating the tests and a test management tool for tracking the test results.
