## Hard Rules
1. **Headed mode mandatory** — no headless (AH Rule 17)
2. **localhost URLs** -> `node scripts/fetch-local-page.js`. WebFetch cannot reach localhost.
3. **Two-source model** — Epic ACs = assertions. DOM = locators ONLY. Never derive expected behavior from the UI (AH Rule 19).
4. **Test failing != wrong test** — investigate before modifying. A test correctly catching an app bug must NOT be "fixed".
5. POM variable names must match actual UI text. No invented names.
6. **Dedup before filing** — check `knowledge-base/{JIRA_PROJECT}/known-defects.md`, then JQL (AH Rule 21/25).
7. **Confidence tiers** — REAL_BUG violating a `BR-xx` = **Confirmed** (cite it). Heuristic only = **Suspected** (AH Rule 25).
8. **pressSequentially() not fill()** for constraint tests (AH Rule 18).
9. **Per-run outputDir** — every run writes to `test-results/{RUN_ID}`. Never overwritten (AH Rule 31).
10. **Never invent** selectors, `BR-xx` rules, error text, or URLs.
11. **Stay in command scope** — only the command's deliverable (AH Rule 26).
12. **Test failing != app broken** — re-derive your own expected value before assigning REAL_BUG (AH Rule 32).
13. **Never pass `--reporter=line`** when artefacts are needed — it overrides all config reporters (Allure + JSON produce nothing).

## Failure Taxonomy (AH Rule 23 — classify BEFORE any fix)
| Category | Signals | Action |
|---|---|---|
| `BROKEN_LOCATOR` | resolved to 0 elements | Auto-patch POM |
| `REAL_BUG` | element visible+enabled, no effect | File bug + tier it |
| `FLAKY` | passes on retry | Tag `@flaky` |
| `ENV_ISSUE` | auth/network failure | Check env |
